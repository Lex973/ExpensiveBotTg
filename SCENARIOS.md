# Проверенные сценарии

Проверки запускаются командой `python -m unittest discover -s tests -v` на отдельных временных базах и подставном Telegram API. Реальные пользовательские операции не используются.

## Правила сохранения

- Новая операция до кнопки «Сохранить» — черновик. «Отмена», `/cancel`, `/start` и переход к другому разделу не сохраняют его.
- Редактирование сохраняет исходную операцию до явного подтверждения. «Отмена» отбрасывает изменения и показывает исходную запись с пояснением.
- «Исправить» на экране проверки возвращает к вводу черновика. Это ещё не сохранение.
- «Удалить» — отдельное действие с подтверждением. Отмена удаления сохраняет запись. Удаление пересчитывает балансы и аналитику.
- Счета, категории, бюджеты и цели в текущих текстовых формах сохраняются после корректного ввода; доходы, расходы и переводы требуют отдельного подтверждения.

## Покрытие

| Область | Сценарии |
| --- | --- |
| Создание | Доход, расход, перевод; отмена на разных шагах, некорректный ввод, подтверждение |
| Редактирование | Оригинал до сохранения; отмена на каждом шаге; изменение без дубликата |
| Удаление | Подтверждение и отмена; повтор нажатия; возврат обоих балансов после удаления перевода |
| Навигация | Переходы сбрасывают черновик; прежние кнопки и сообщения не меняют новый экран |
| Доставка | Повторный update не заполняет новый черновик; задержка подтверждения кнопки не меняет порядок ввода |
| Ошибки ввода | Суммы, даты, категории другого типа; после ошибки можно продолжить или отменить |
| Состояние | Восстановление черновика и версий кнопок после перезапуска без автосохранения |
| Данные | Изоляция пользователей; точные суммы; бюджеты, цели, переводы и сравнения периодов |
| Выгрузка | Входящие переводы в отчёте счёта; нейтрализация формул CSV |

## Защита кнопок

Каждая отрисовка получает случайную версию, записанную в `ui_panels`. Бот принимает только кнопки последней версии, присутствующие на текущем экране. Это защищает от запоздалого «Сохранить» предыдущей операции и повторных подтверждений. Версия хранится в базе и сохраняется при перезапуске.

`handled_updates` хранит последний обработанный update пользователя. Внутри одного чата обработка последовательная, блокировка берётся до обращения к Telegram за подтверждением нажатия.

## Практические ограничения

Автотесты не заменяют проверку внешнего вида на телефоне и реальной доставки Telegram. Для ручного smoke-теста: создать доход → проверить баланс → начать редактирование → изменить сумму → отменить → проверить исходную сумму → удалить с подтверждением. Отдельно проверить отмену новой операции до сохранения.

При разрыве сети оформление может обновиться с задержкой. После аварийного завершения процесса в момент записи/отправки нельзя обещать абсолютно однократную доставку внешних сообщений; банковская транзакционная система и полноценная очередь исходящих сообщений здесь не реализованы.
