# Бесплатный запуск на Waifly

Waifly заявляет постоянный бесплатный тариф без банковской карты: один работающий сервер, 300 МБ RAM, 30% CPU и 1 ГБ диска. Текущий бот использует только стандартную библиотеку Python и укладывается в эти ресурсы.

## Создание сервера

1. Зарегистрируйтесь на [dash.waifly.com](https://dash.waifly.com/). Для бесплатного тарифа платёжные данные не нужны.
2. Откройте **Servers → Create**.
3. Имя: `Expense Bot`.
4. Egg / Runtime: `Python`.
5. Локация: `FR2 Paris`; если нет места, выберите `FR1`.
6. Оставьте бесплатные лимиты: 300 МБ RAM, 30% CPU и 1024 МБ диска.
7. После создания откройте ссылку на Pterodactyl Panel. У панели отдельный пароль; его можно сбросить через **Account → Reset Panel Password** в основном кабинете.

## Загрузка кода

1. Откройте **Files** в Pterodactyl Panel.
2. Загрузите `ExpenseBot-Waifly.zip`.
3. Нажмите меню файла и выберите **Unarchive**.
4. Убедитесь, что `run.py`, `requirements.txt` и папка `expense` находятся непосредственно в корне сервера.
5. Скопируйте `.env.example` в `.env` или создайте `.env` в файловом менеджере со следующим содержимым:

```text
TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН_ИЗ_BOTFATHER
DATABASE_PATH=data/expense.db
UTC_OFFSET_HOURS=5
AI_ENDPOINT=
AI_API_KEY=
```

Не добавляйте `.env` в GitHub и не публикуйте токен.

## Запуск

В разделе **Startup** выберите актуальную стабильную версию Python и укажите точку запуска `python run.py`. В некоторых вариантах Python Egg поле содержит только имя главного файла — тогда укажите `run.py`.

Откройте **Console** и нажмите **Start**. Успешный запуск содержит строку:

```text
Бот запущен. Ожидание сообщений.
```

После этого отправьте боту `/start`.

## Перенос текущей базы

Если нужно сохранить уже добавленные операции:

1. Остановите локальный бот и сервер Waifly.
2. Создайте через Files папку `data`.
3. Загрузите локальный `data/expense.db` как `data/expense.db`.
4. Запустите сервер.

Одновременный запуск локальной и серверной копий с одним Telegram-токеном вызовет конфликт `getUpdates`.

## Резервное копирование

Периодически остановите бот и скачайте `data/expense.db`. Бесплатная сторонняя площадка не должна быть единственным местом хранения финансовых данных.

Waifly автоматически приостанавливает сервер, который оставался выключенным три дня. Работающий бот это правило не нарушает. Не используйте аккаунт для VPN, прокси или туннелей — это запрещено правилами бесплатного тарифа.
