# Бесплатный запуск на Bothost

Bothost заявляет бесплатный тариф для одного бота 24/7 без банковской карты: 256 МБ RAM, 0,25 vCPU и 0,5 ГБ SSD. Этого достаточно для текущего Expense Bot. Условия бесплатного стороннего сервиса могут измениться, поэтому регулярно скачивайте резервную копию базы.

## Подготовка

Пакет `ExpenseBot-Bothost.zip` уже подготовлен. В нём нет `.env`, Telegram-токена, локальной базы и пользовательских данных.

Для развёртывания Bothost использует Git-репозиторий:

1. Создайте пустой публичный репозиторий на GitHub или GitLab.
2. Распакуйте `ExpenseBot-Bothost.zip` в отдельную папку и загрузите его содержимое в репозиторий.
3. Зарегистрируйтесь на [Bothost](https://bothost.ru/register). Карта не требуется.
4. Создайте бота и укажите:
   - платформа: `Telegram`;
   - Git URL: адрес созданного репозитория;
   - ветка: `main`;
   - главный файл: `run.py`.
5. Вставьте токен Telegram в поле Bot Token. Публиковать токен в Git нельзя.
6. В переменных окружения добавьте:

```text
DATABASE_PATH=/app/data/expense.db
UTC_OFFSET_HOURS=5
```

Bothost передаёт токен приложению как `TELEGRAM_BOT_TOKEN`, что уже поддерживается ботом. Каталог `/app/data` сохраняется между обновлениями.

## Перенос существующих операций

Чтобы перенести текущие данные:

1. Остановите локальный бот.
2. В файловом менеджере Bothost откройте каталог `/app/data`.
3. Загрузите туда локальный файл `data/expense.db` под именем `expense.db`.
4. Запустите или перезапустите бот в панели.

Одновременно держать локальную и серверную копии с одним токеном нельзя: Telegram остановит один из процессов с конфликтом `getUpdates`.

## Проверка

В логах должна появиться строка `Бот запущен. Ожидание сообщений.` После этого отправьте боту `/start`, добавьте тестовый доход и проверьте историю.

Если приложение не запускается, проверьте три настройки: `run.py`, токен и `DATABASE_PATH=/app/data/expense.db`.

## Резервные копии

Периодически остановите бот, скачайте `/app/data/expense.db` через файловый менеджер и снова запустите его. Это особенно важно для финансовых данных на бесплатном хостинге.
